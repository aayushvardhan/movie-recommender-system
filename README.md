# 🎬 Movie Recommender System

A content-based movie recommendation system built using Python, Streamlit, and the TMDB API.

## 🚀 Live Demo

👉 [Try the Movie Recommender](https://movie-recommender-system-ivu4.onrender.com)

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TMDB API

## ✨ Features

- Select a movie
- Get 5 recommended movies
- Display movie posters
- Content-based movie recommendations
